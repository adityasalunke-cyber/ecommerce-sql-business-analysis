# Dataset

The project queries are written for the `ecommerce_practice` MySQL database used during the analysis.

The database contains:

- 150 customers
- 130 products
- 500 orders

Tables:

- `customers`
- `products`
- `orders`

Revenue analysis uses only `Delivered` orders and the `total_amount` column.

The original dataset SQL can be added here as `ecommerce_dataset.sql` when uploading the source dataset file.
